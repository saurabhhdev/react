## 📌 Repository Overview

This repository documents a step-by-step curriculum for mastering **React.js**. Instead of isolated theory, each milestone is anchored by practical implementations — progressing from component composition and prop hierarchies to complex reactive state management and interactive web applications.

---

## 🗺️ Curriculum & Project Roadmap

| Module | Project / Topic | Focus & Key Concepts | Level |
| :--- | :--- | :--- | :---: |
| [`01-components`](./01-components) | **Component Architecture** | Functional components, JSX syntax, virtual DOM mechanics | `Foundational` |
| [`02-props`](./02-props) | **Dynamic Props & Reusability** | Data passing, prop destructuring, children props, default values | `Foundational` |
| [`03-cards-project`](./03-cards-project) | **Cards Grid Project** | Mapping data arrays, key props, grid layouts, component isolation | `Beginner` |

## 🚀 Featured Capstone Projects

### 🎵 07. VibeBox Music Studio
> An interactive audio discovery platform featuring playlist curation and music filtering.

- **Real-Time Search & Filtering**: Instant query matching by song title and artist.
- **Genre Classification**: Filter tracks across Rock, Pop, Indie, Electronic, and Acoustic.
- **Playlist Architecture**: Create custom playlists, append tracks dynamically, and manage playback states.
- **State Coordination**: Complex multi-level state sharing across songs, favorites, and playlists.

---

### 📝 06. Interactive Notes App
> A sleek, responsive productivity tool for capturing thoughts, ideas, and tasks.

- **Full Lifecycle**: Create, edit, search, and delete note records.
- **Controlled Forms**: Controlled inputs with validation and submission handlers.
- **Responsive Layout**: Designed for seamless usability across mobile, tablet, and desktop viewports.
